# 西洋美術史を旅する — iPhoneだけで使う方法

これはiPhone向けのWebアプリ（PWA）です。MacやXcodeは不要です。Safariで開いたWebページをホーム画面に追加すると、アプリのように起動できます。

## 最初に
このフォルダには `index.html`、`manifest.json`、`sw.js` が入っています。**PWAとしてホーム画面に追加するには、HTTPSで公開する必要があります**。iPhoneの「ファイル」アプリからHTMLを直接開くだけでは、ホーム画面アプリとして正常に動かないことがあります。

## iPhoneだけで公開する手順（GitHub Pagesの例）
1. Safariで GitHub にアクセスし、アカウントを作成またはサインインします。
2. 新しい公開リポジトリを作ります（例：`art-history-study`）。
3. リポジトリ画面の **Add file → Upload files** から、このZIPを事前に「ファイル」アプリで展開し、中の3ファイル（`index.html`、`manifest.json`、`sw.js`）をアップロードしてコミットします。
4. リポジトリの **Settings → Pages** を開き、公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` にして保存します。
5. 公開URLが表示されたら、iPhoneのSafariでそのURLを開きます。
6. Safariの共有ボタン → **ホーム画面に追加** を選びます。表示名を確認して追加します。
7. ホーム画面の「西洋美術史」アイコンから起動できます。

GitHubの画面表記は変更されることがあります。公開リポジトリになるため、個人情報や秘密情報をアップロードしないでください。

## 入っている機能
- 古代から現代までの8時代の学習
- 時代背景、表現の特徴、画家、代表作、時代比較
- 8問の解説付きクイズ
- 学習済み記録（ブラウザ内に保存）
- 初回読み込み後のオフライン対応（ブラウザがService Workerをサポートする場合）

## 制限
- ネイティブiOSアプリ（.ipa）ではなく、ホーム画面から起動するWebアプリです。
- 名画の実画像はまだ含めていません。画像を追加する場合は、美術館等の利用条件を確認する必要があります。
- 学習進捗は端末のブラウザ内に保存されます。ブラウザデータを消去すると失われる場合があります。
